# AEO Diagnostic 🔍
The Google Search Console — but for AI.

## What is AEO?

AEO = Answer Engine Optimization

Shoppers are shifting from Google to AI. When someone asks ChatGPT "best magnesium supplement for seniors" — it names specific brands. Those brands win. The ones not mentioned? Invisible.

Amazon sellers have no idea how they rank in AI search. This tool fixes that in 30 seconds.

## Live Demo

https://aeo-diagnostic.vercel.app

## Features

- AI Visibility Score — animated gauge showing what % of AI engines mention your brand
- Brand Leaderboard — auto-extracts every brand from all 3 AI responses, ranked by mentions
- Strategic Insights — 3 actionable tips generated by AI based on the results
- Keyword Extractor — exact words and phrases AI engines use when recommending top brands
- Improve My Listing — paste your Amazon listing, get an AI-optimized version
- AI Consistency Score — runs same query 3x to test how reliable each AI's recommendations are
- Session History — track all queries and scores in one session
- Fuzzy Brand Matching — typos still get detected
- Did you mean? — suggests real brands when yours scores 0%

## Tech Stack

- Framework: Next.js 14 (App Router)
- Language: TypeScript
- Styling: Tailwind CSS
- AI Engine 1: OpenAI GPT-4o
- AI Engine 2: Llama 3.3 70B via Groq (free tier)
- AI Engine 3: Google Gemini 2.0 Flash (free tier)
- Deploy: Vercel

## Local Setup

Step 1 — Clone the repo

    git clone https://github.com/bhavanakalloli/aeo-diagnostic.git
    cd aeo-diagnostic

Step 2 — Install dependencies

    npm install

Step 3 — Set up API keys

Copy .env.example to .env.local and fill in:

    OPENAI_API_KEY=sk-...       (platform.openai.com/api-keys)
    GROQ_API_KEY=gsk_...        (console.groq.com — free!)
    GEMINI_API_KEY=AIza...      (aistudio.google.com — free!)

Step 4 — Run locally

    npm run dev

Open http://localhost:3000

## Deploy to Vercel

1. Push to GitHub
2. Go to vercel.com/new
3. Import your repo
4. Add environment variables (OPENAI_API_KEY, GROQ_API_KEY, GEMINI_API_KEY)
5. Click Deploy

## How it works

User types query + brand name
        ↓
App hits 3 AI engines simultaneously
  - OpenAI GPT-4o
  - Llama 3.3 70B via Groq
  - Google Gemini 2.0 Flash
        ↓
Parse each response for brand mentions
        ↓
Generate report card:
  - Visibility score (0-100%)
  - Brand leaderboard
  - Keyword extractor
  - AI consistency score
  - Strategic insights
